# Ganga-Bhawan-web

🏨 **Ganga Bhawan Hostel Management Website**

A web-based application built using **React + Vite** to manage hostel-related information such as tenants, rooms, and administration workflows.

---

## 🚀 Tech Stack
- React
- Vite
- JavaScript
- HTML
- CSS

---

## 🛠️ Features
- Fast development with Vite
- Modern React setup
- Scalable project structure
- Ready for backend integration
